# KLMS Calendar Sync - Chrome拡張機能

KLMSの課題を自動的にカレンダーアプリに同期するChrome拡張機能です。

## 機能

- KLMSダッシュボードから課題情報を自動抽出
- 課題のタイトル、期限、科目情報を取得
- カレンダーアプリのTodoリストに自動追加
- 重複チェック機能で同じ課題を複数回追加しない
- 「KLMS課題」カテゴリを自動作成

## インストール方法

### 1. アイコンファイルの準備

`chrome-extension/icons/` フォルダに以下のサイズのアイコンを配置してください：
- `icon16.png` (16x16px)
- `icon48.png` (48x48px)
- `icon128.png` (128x128px)

簡易的な方法として、任意の画像ファイルをこれらのサイズにリサイズして配置できます。

または、以下のサイトで無料のアイコンを作成できます：
- https://www.favicon-generator.org/
- https://realfavicongenerator.net/

### 2. Chrome拡張機能としてインストール

1. Chromeを開き、`chrome://extensions/` にアクセス
2. 右上の「デベロッパーモード」をONにする
3. 「パッケージ化されていない拡張機能を読み込む」をクリック
4. `chrome-extension` フォルダを選択

## 使い方

### 1. 初回設定

1. 拡張機能アイコンをクリック
2. 「カレンダーアプリのURL」に以下のいずれかを入力：
   - ローカル開発: `http://localhost:8081`
   - 本番環境: `https://your-app.vercel.app` (実際のVercel URLに置き換え)
3. URLは自動的に保存されます

### 2. 課題の同期

1. KLMSにログインしてダッシュボード（https://lms.keio.jp/?login_success=1）を開く
2. 拡張機能アイコンをクリック
3. 「課題を同期」ボタンをクリック
4. 抽出された課題が表示され、カレンダーアプリに自動追加されます

## 注意事項

- **認証**: カレンダーアプリにログインした状態で使用してください
- **対応ページ**: KLMSのダッシュボードページでのみ動作します
- **重複**: 同じタイトルと期限の課題は自動的にスキップされます
- **カテゴリ**: 初回実行時に「KLMS課題」カテゴリが自動作成されます

## トラブルシューティング

### 課題が抽出されない

- KLMSのページ構造が変更された可能性があります
- ブラウザのコンソールを開いて（F12）エラーメッセージを確認してください

### カレンダーアプリへの送信が失敗する

- カレンダーアプリにログインしているか確認してください
- URLが正しいか確認してください
- CORSエラーの場合、アプリ側でCORS設定が必要です

### エラーメッセージ: "Unauthorized"

- カレンダーアプリでログインしていない可能性があります
- カレンダーアプリを開いてログインしてから再度お試しください

## 開発者向け

### ファイル構成

```
chrome-extension/
├── manifest.json       # 拡張機能の設定
├── content.js         # KLMSページから課題を抽出
├── popup.html         # ポップアップのUI
├── popup.js           # ポップアップのロジック
├── icons/             # アイコンファイル
│   ├── icon16.png
│   ├── icon48.png
│   └── icon128.png
└── README.md          # このファイル
```

### カスタマイズ

`content.js`の抽出ロジックを変更することで、KLMSのページ構造の変更に対応できます。
